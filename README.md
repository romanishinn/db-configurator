Конфигуратор и калькулятор КП для линейки Sun Winner: перголы Win Climatic (S400, S500, Slide), Win Screen ZIP, Win Glass, Win Panels, Win Verto.

Архитектура и решения — в документе «Конфигуратор Sun Winner — архитектура» (Claude Docs).

## Как устроены данные

Каждая таблица — JSON с источником (файл каталога + страница), осями (ширина × вылет, мм) и ценами (каталожные EUR нетто).
Размер между ступенями сетки считается по следующей ступени вверх (примечание 6 прайса).

Импорт: `tools/import/build_pergolas.py`. Каталоги PDF в репозиторий не кладём — путь задаётся через `SW_PDF_DIR`.
Контроль качества при импорте:

1. Два независимых парсера (по тексту и по символам) — их результаты должны совпасть до цента.
2. Строку, найденную только одним парсером, сверяем с картинкой страницы и вносим в `VERIFIED_SINGLE`.
3. Строку, не найденную ни одним парсером, вносим вручную в `MANUAL` по картинке страницы.
4. Проверка полноты сетки и роста цены вместе с размером.
5. Эталонные тесты: цены, считанные прямо со страниц каталога.

```bash
SW_PDF_DIR=/path/to/Price python3 tools/import/build_pergolas.py
pnpm install && pnpm test
```

## Правила для разработки

- Цена считается только на сервере. В браузер не уходят ни сетки прайса, ни закупочные цены.
- Каждая строка расчёта несёт `source` — откуда взята цифра.
- Новая версия прайса — новая папка `data/sunwinner/<версия>/`; старые КП остаются на своей версии.
- Допущения помечаются в коде как `ASSUMPTION` и выносятся в вопросы к Sun Winner.
