Работает в проде и проверено по всем путям: клиентский интерфейс, CRM, КП на немецком и английском, работа без БД, правила доступа в SQL. Зелёные тесты и скриншот — это только «реализовано».

## Решено (подробности и цитаты: `docs/decisions.md`)
- Хостинг: GitHub Pages + Actions; логин, роли, данные — Supabase PostgreSQL (ЕС). Других бэкендов нет.
- Маржи, закупочных цен и скидок производителя в репозитории, сайте и БД нет. Производитель по имени нигде не называется.
- Для важных решений владелец может подключить внешний взгляд `/founder` (только по его слову; финансовые выводы только в личном документе на его Google Drive, не в репозитории; выводы — гипотезы).
- **Репозиторий публичный.** В нём и на сайте не должно быть: финансовой модели и цифр, списка запрещённых имён, имён производителей (решение владельца 04.11). Финансы — личный документ на Drive, список имён — секрет GitHub `REDLINE_TERMS` (место владельцу неважно).
- Работаем по харнессу (`docs/harness/README.md`); владелец подтвердил 04.11.
- Проекты на лендинг добавляют суперадмин и менеджер; роль «продавец» переименовывается в «менеджер», менеджеров будет много.
- Удаляет проекты только суперадмин; менеджер добавляет и правит. Менеджеры регистрируются сами, роль ставит суперадмин. Менеджер — сотрудник D&B (запись 04.11, «Роли и доступ»; расшифровка «1а, 2а, 3а» — интерпретация оркестратора).
- Поток дилера v1 разрешён к сборке (миграция 0010; запись 04.11, «Роли и доступ»; расшифровка 1а, 2а, 3а — интерпретация оркестратора): заявка только из заказа в этапе «смонтирован»; менеджер создаёт заказ из выигранного лида и отмечает «Монтаж завершён»; согласие владельца объекта (подтверждённое офисом) обязательно для публикации любого проекта, включая добавленные офисом; проверка на втором проекте Supabase во Франкфурте (сначала проверить, что создание бесплатно).
- Агент = дилер (группа скидок agent); отдельной роли агента нет. Видение потока: дилер присылает проект на проверку, менеджер (человек в офисе) проверяет, удаляет ненужные фото, правит текст и орфографию, публикует (запись 04.11, «Роли и доступ»; сведение к дилеру — интерпретация оркестратора).
