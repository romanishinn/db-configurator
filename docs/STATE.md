## Цель
Рабочий продукт D&B Solutions: конфигуратор пергол с ценой → заявка → CRM → КП; B2C-лендинг на немецком с доказательствами (реальные проекты) для запуска рекламы в Вене. Видение: `docs/vision.md`.
## «Готово» значит
Работает в проде и проверено по всем путям: клиентский интерфейс, CRM, КП на немецком и английском, работа без БД, правила доступа в SQL. Зелёные тесты и скриншот — это только «реализовано».
## Решено (подробности и цитаты: `docs/decisions.md`)
- Хостинг: GitHub Pages + Actions; логин, роли, данные — Supabase PostgreSQL (ЕС). Других бэкендов нет.
- Маржи, закупочных цен и скидок производителя в репозитории, сайте и БД нет. Производитель по имени нигде не называется.
- Налог и юрлицо (04.11): НДС австрийский 20 % для всех языков и стран; пока все предложения от австрийской компании («пока» = не окончательно).
- `/founder` (внешний взгляд) только по слову владельца; финансовые выводы только в личном документе на Drive, не в репозитории; выводы — гипотезы.
- **Репозиторий публичный.** Не должно быть: финансовой модели и цифр, списка запрещённых имён, имён производителей. Финансы на Drive; список имён в секрете GitHub `REDLINE_TERMS`.
- Работаем по харнессу (`docs/harness/README.md`).
- Роли: суперадмин, менеджер (сотрудник D&B, бывш. «продавец»), дилер и superdealer, клиент. «Агент» = дилер в группе скидок `agent` («Агенты»). Проекты на лендинг: добавляют суперадмин и менеджер, удаляет только суперадмин.
- Поток дилера (09.11 на проде): заявка только из заказа в «Монтаж завершён» (подтверждает офис); публикация только с согласием владельца объекта, записанным офисом; район скрыт без согласия; EXIF/GPS убирается пересжатием.
- Галерея объектов (09.11): папка Google Drive, видят менеджеры и дилеры; ссылка хранится в БД (`app_links`), вносит суперадмин на `hub.html`; в репозитории и на публичном сайте её нет.
- Форма лендинга шлёт заявку на звонок (`submit_callback`, только service_role); согласие хранится с датой (`leads.consent_at`). «Делай» владельца без варианта понято как «согласие с датой» (интерпретация).
- Лендинг: вместо «26 монтажников в Хорватии» стоит «Zertifizierte Montageteams in Österreich und Kroatien» (слово «zertifiziert» владелец должен подтвердить фактом).
- Угловая стойка (10.11): стекло/ZIP/панели боковой стороны короче на сдвиг, передняя сторона на полную ширину.
