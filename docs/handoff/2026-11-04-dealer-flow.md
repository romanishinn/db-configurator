1. **Слияние в `main`**: ТОЛЬКО по слову владельца (применит `0010` на боевую БД и выложит `submit.html`, `projects.html`). До слияния желательно пройти пункт 2.

Блокеры: (а) подключение Supabase MCP просит подтверждение владельца на миграции с `drop policy` (запрос уходит в клиент владельца); (б) сеть облачной среды закрыта для `*.supabase.co` (разрешить в настройках окружения: Edit → Network access). Что делать: сбросить схему стенда (с подтверждением) и накатить `0001`–`0010` ПО ОДНОЙ и строго по порядку, затем проверки: права по умолчанию на новые функции (anon не вызывает), настоящий `storage.foldername`, политики `storage.objects`, сквозной сценарий дилер → менеджер → аноним. С Мака проще: добавить в `~/.pgpass`/переменную строку подключения стенда и выполнить `sh db/migrate.sh` (пароль сбросить в панели Supabase; в репозиторий и в чат не писать).
3. **Ручная проверка на стенде или прод** (никакая заглушка этого не заменяет): добавить заказ и довести до «Монтаж завершён», прислать заявку тестовым дилером с реального телефона (проверить, что в загруженном файле нет GPS: `exiftool`), опубликовать менеджером, убедиться, что старая ссылка на удалённый файл отдаёт 404, что аноним не видит район без согласия, что CORS публичных ссылок Storage позволяет менеджеру перекодировать фото (иначе публикация остановится сообщением).
4. Исправления по результатам и, при желании владельца, третий круг ревью.

## Известные ограничения и допущения
- Настоящий Supabase SDK и Storage в тестах подменены заглушкой; EXIF/GPS на реальном снимке не проверен; CORS публичных адресов Storage (нужен для перекодирования фото менеджером) не проверен.
- Заказов на боевой БД 0: дилеру нечего выбрать, пока менеджер не создаст заказ из выигранного лида и не нажмёт «Монтаж завершён» (экран «Заказы»). Лидов 4, проектов 0, профилей 2 (суперадмин, дилер), менеджеров 0.
- Ссылки на право (GDPR, § 78 UrhG, Хорватия) даны советниками, не перепроверены; текст формы согласия до первой публикации должен проверить юрист. Это не юридическая консультация.
- Список запрещённых имён (секрет `REDLINE_TERMS`) не задан: имя производителя автоматически не проверяется.
- Хвосты, вопросы владельцу и ветки вне `main`: `docs/STATE.md`.

## Как продолжить на другом компьютере (Mac)
`git clone` репозитория (или `git fetch`), `git checkout ccr-deb119a7-354qzr`, `pnpm install`. Локальная сессия Claude Code в папке репозитория сама подхватит хук старта (`docs/STATE.md`) и роли `.claude/agents/`. Для тестов БД нужен локальный PostgreSQL (на Mac: `brew install postgresql@16`); `sh db/test/run.sh` и `sh db/test/upgrade.sh` поднимают временный кластер сами. Секретов в репозитории нет и быть не должно.
